# objective-node-test
API RESTful para locação de filmes desenvolvida em Node.js e TypeScript. Implementada sob a arquitetura de Monólito Modular, utilizando princípios de Clean Architecture e DDD para garantir baixo acoplamento, alta testabilidade e escalabilidade. Solução containerizada com Docker e persistência em MongoDB.
